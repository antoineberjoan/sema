# Source de référence

Le dépôt public `antoineberjoan/sema` réunit le code de l’application et de son site sous [licence MIT](../LICENSE).

- Application : `Sources/`, `Tests/`, `Resources/` et `scripts/`.
- Site et identité visuelle : `site/`.
- Distribution : `distribution/`, manifeste de release et copie du cask public.

Les versions binaires pour macOS et le cask Homebrew sont disponibles dans [homebrew-sema](https://github.com/antoineberjoan/homebrew-sema). La version courante et ses vérifications sont décrites dans [le guide de distribution](DISTRIBUTION.md).
